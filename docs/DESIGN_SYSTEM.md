# 视觉与动效规范

版本：0.1（阶段二原型）

适用范围：首页、模型目录、模型详情及公共指南。

状态：规范随阶段二原型建立；颜色与断点记录依据当前 `src/styles/global.css`，以代码为准。

## 视觉方向

采用精密产品目录的视觉语言：银灰纸面承载内容，石墨色用于正文与结构，深青色用于链接、操作和状态提示。页面通过细边框、低对比渐变、留白和克制的阴影体现材质；避免大面积高饱和色、厚重卡片和装饰性动效。模型名称、用途、规模、许可和核实日期优先保持清楚可读。

## 布局与组件

- 页面主体最大宽度为 1200px，桌面两侧至少保留 32px；宽屏增加留白而非无限拉长正文。
- 760px 以下切换为单列内容与窄屏目录工具布局；480px 以下收紧页边距、导航、对比栏和长字段排版。320px 为支持的最小视口，正文不应产生非预期横向滚动。
- 首页强调一个清楚的标题与目录入口；不展示标题下的说明段落，装饰图形不得遮挡内容或交互。
- 模型卡片以标题和用途建立层级，参数、许可、核实时间为次级信息；悬停阴影与轻微位移仅作为补充反馈。
- 筛选控件需有可辨认的选中状态；比较栏固定显示已选数量、条目摘要和用途不匹配说明。窄屏下限制比较栏高度并允许内部滚动。
- 部署步骤沿用原生 `details/summary`，在不依赖脚本时仍可展开阅读。
- 可操作控件应有清晰焦点样式。触控目标以至少 44×44 CSS px 为项目设计目标；信息密集处如需缩小，应保留足够间距，并满足 WCAG 2.2 目标尺寸最低要求。

## 动效规范

动效用于说明状态变化和空间关系，不延迟输入、不隐藏信息、不制造持续运动。常规颜色与焦点反馈使用 `--duration-fast`（180ms）；筛选重排使用 `--duration-layout`（240ms）。只在确有需要时做布局动画，优先使用 `transform` 与 `opacity`；避免反复触发布局和滚动位置跳变。

目录原型使用 Web Animations API 对筛选或排序后的卡片位置做短暂过渡，时长 240ms；用户开启减少动态效果时跳过这段布局动画。页面 CSS 也通过 `prefers-reduced-motion: reduce` 缩短过渡、关闭平滑滚动。新增脚本动画必须读取相同偏好，动态偏好变化后应停止后续非必要动画。Astro 客户端脚本由框架处理、打包为模块；参见 [Astro 客户端脚本](https://docs.astro.build/en/guides/client-side-scripts/) 与 [MDN `Element.animate()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)。

部署步骤展开与复制反馈使用 180ms 的透明度和轻微位移动效。详情页提供官方链接复制，数据存在命令时显示命令复制；缺失命令不补造。阶段三补充了有官方来源的 Kokoro 安装命令，未作为本站推理实测。复制使用 Clipboard API，并向用户提供成功或失败文本；无安全上下文或浏览器拒绝权限时保留可手动选择的内容。状态文字使用 `aria-live="polite"`，不只通过颜色或图标表达。参见 [MDN `Clipboard.writeText()`](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)。

## 可访问性与输入方式

- 语义化标题按层级排列；每页只有一个主标题。导航、筛选、排序、比较与跳过链接提供可访问名称。
- 所有功能支持键盘操作，焦点顺序跟随阅读顺序；`:focus-visible` 轮廓不得被裁切或被固定浮层遮挡。
- 状态通过原生按钮、表单控件、`aria-pressed`、`aria-live` 等合适语义暴露；隐藏条目不留在可访问树中。
- 文本缩放至 200% 和窄屏下仍能阅读与操作。颜色对比按 WCAG 2.2 AA 检查，链接与普通文字在正文中保持可区分。
- 桌面悬停效果必须同时有键盘焦点或触控下的等价反馈。操作不能只依赖 hover、拖动或精细指针。
- 移动端先纵向阅读；筛选与比较入口必须可见、易点，固定栏需考虑安全区与页面底部内容遮挡。

## Astro 与渐进增强

静态 HTML 是内容和主要导航的默认载体。简单展开优先使用原生 HTML；需要筛选、重排或临时比较时，再由 Astro 客户端脚本增强。脚本应作用于本组件的标记，不假定客户端脚本一定可用；筛选原型无法运行时至少仍应能浏览模型条目。Astro 默认处理组件 `<script>`，可打包、去重并作为模块加载；需要内联脚本时须明确评估其影响。

阶段二用于审阅颜色、材质、排版、断点、卡片和代表性交互反馈，维护者已确认。阶段三已完善搜索与组合筛选、可恢复和分享的 URL 状态、同用途选择限制、完整对比详情、命令复制及错误反馈，并覆盖刷新、浏览器前进后退、键盘和窄屏模拟。对比卡片沿用 14px 圆角，小控件使用 8px 圆角；错误和未知值保持文字说明，不呈现统一智能排名。
