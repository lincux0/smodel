# 能力依据与评测整理

## 范围

能力依据由按用途的编辑结论、原始评测成绩、评测条件及来源组成。结论帮助判断适用场景，不是通用智能等级，也不是本站推理实测。当前对目录全部 21 个型号逐用途开展证据审核；找不到准确型号、来源身份或使用条件明确的成绩时，保留证据不足结论并说明缺口。仍使用人工核实、JSON 维护与 Astro 静态发布，不新增数据库、在线抓取或推理服务。

## 编辑规则

首批包含 20 条成绩和 12 条用途摘要，均为官方报告依据。本轮扩展到全目录，并在能准确匹配型号时补充独立来源；最新逐型号覆盖及出处见 [来源记录](SOURCES.md)。公开条件不足的记录保留不可比状态，没有成绩不等于能力为零。

2026-10-02全目录审核完成：21个型号、35个用途摘要、92条成绩（77条官方、15条第三方），均保留不可比状态。证据不足仍有3个用途：Kokoro音质、Coder 1.5B通用文本、all-MiniLM的充分交叉验证；后者已有社区成绩但提交者关系未知。

2026-10-06多来源整理：原92条成绩的指标、数值、单位、配置与权利说明全部保留，新增5条，合计97条（77官方、20第三方）。新增为Qwen3-8B的两条Epoch AI OTIS数学记录及Qwen3-Embedding-0.6B的三条MTEB/HUME分项。14条第三方记录标为已核实独立关系，6条社区记录仍为关系未知；条数不等于评测者数量。35个用途摘要中7项独立多来源佐证、24项仅官方、1项独立性待确认、3项证据不足；全部成绩仍不可比。Arena完整快照及部分平台的具体结果许可未核完，不把待核实写成没有成绩，也不导入未确认记录。

- 每个用途单独判断。英文知识成绩不外推中文写作，图像理解成绩不外推语音能力，OCR 文字行识别不外推完整文档流程。
- 只摘录准确对应型号的少量指标事实，链接具体报告；不能把其他尺寸、英文专用变体、蒸馏模型或完整流水线的成绩移植到当前型号。
- 按实际评测者标记官方、第三方或本站实测。官方数据被转载不构成独立复测，排行榜收录也不自动构成独立证据。
- `assessments` 为本站原创编辑总结，关联同用途评测 ID。优势和限制由证据支持，不依据一个高分断言“最佳”“中文优秀”或实际部署表现。
- 证据状态与能力高低分开：`official-only` 为仅官方报告，`single-source` 为已确认的单一评测者，`independence-unverified` 为存在评测关系待确认的依据，`corroborated` 为独立多来源佐证，`insufficient` 为证据不足。交叉佐证允许不同独立第三方，不再强制其中一方必须是官方；关系未知记录不能提升状态。独立性仍需人工审查，结构校验不能代替事实核实。
- 不求官方与第三方成绩平均数，不制作跨用途总分。保留条件差异；低分、失败和未知不能选择性删除。
- 条件未知保留 `null` 或 `unknown`，不能从使用示例反推评测设置。核实日期不是评测日期或权重 revision。

## 数据与展示

结构以 [catalog.ts](../src/lib/catalog.ts) 为准。原有评测字段保留，记录身份 `id`、任务 `task`、评测者 `publisher` 和 `externalModelId`；`provenance` 记录实际评测者的稳定 `sourceId`、报告/运行批次 `runId` 与 `independence`。同一批次多个指标允许共存，同一批次同一口径的转载拒绝重复导入；不同发布网页不自动算不同评测者。`modelConfig` 记录权重 revision、思考模式、量化和运行时；`conditions` 记录划分、shot 数、提示模板和输出预算；`comparisonGroup` 与 `nonComparableReason` 明确比较资格；`rights` 记录使用口径、许可链接和说明。

模型顶层 `assessments` 按用途记录结论、优势、限制和关联 `evidenceIds`，缺省为空数组。详情与对比复用 `CapabilityEvidence.astro`，每个用途以原生 `details/summary` 卡片展示，默认折叠。摘要保留维护顺序首项，其余优先覆盖独立评测者、不同来源及指标，最多显示三项成绩；来源数按 `sourceId` 去重，未知关系来源另提示，不因多指标或多个转载 URL 增加来源数。摘要显示具体发布者、独立性、语言及思考开关，不表示排名。展开显示编辑结论、优势、限制及全部成绩；相同基准、数据集、语言、指标、单位、方向和版本归组，组内分别显示各来源分数与配置，不求平均。每项成绩仍可展开条件、日期、批次与许可。没有记录时说明证据不足，不显示虚构的 0 分。详情阅读和证据展开不依赖 JavaScript；对比沿用已有 URL 选择。

## 可比性与单位

不可比记录必须 `comparisonGroup: null` 并填写原因。可比记录需有组 ID 与明确关键配置；同组任务、基准、数据集、语言、指标、单位、方向、版本、思考模式、量化、运行时与条件不得冲突。模型 revision 区分工件，不要求不同模型 revision 字符串相同。

百分比按 `unit: "%"` 保存，普通准确率百分数为 0–100；WER/CER 因插入错误可超过 100%，不套用准确率上限。比例不能未经说明改成百分数，不同单位不能混排；0 是有效成绩，不是缺失值。平均值保留聚合口径，量化成绩只代表对应工件，API 速度不代表本地设备速度。公开报告条件不足仍可注明限制后引用，但不能加入可比组；记录完整也不保证基准无污染或适用于全部真实任务。

## 来源与使用条件

平台准入、逐型号覆盖和缺口维护在 [评测来源规范](EVIDENCE_SOURCES.md)、[通用/代码/视觉覆盖](EVIDENCE_GENERAL_COVERAGE.md) 与 [检索/语音/OCR 覆盖](EVIDENCE_SPECIAL_COVERAGE.md)。覆盖表的待核实项不能解读为平台一定没有结果。开放数据必须填写明确许可；AA 禁入校验覆盖成绩来源、发布者、许可 URL 与来源标识，但仍不能替代对转载来源的人工审查。

`rights.status` 区分 `citation`（少量事实引用）、`open-data`（核实开放结果数据许可）和 `site-owned`（本站产生的数据）。模型权重、工具代码、结果数据和报告文字许可分别处理。`citation` 不是整份报告或数据集再分发授权，`license: null` 不是“免费开放”。用本站文字表达，保留出处，不复制大段文字、整张官方表格或截图。

### Artificial Analysis

2026-10-02 核对 [AA 数据平台条款 v1.1](https://artificialanalysiscdn.com/legal/ProDataPlatformTerms.pdf)（2026-08-19 修订）及 [API 文档](https://artificialanalysis.ai/data-api/docs)。2.3 允许内部使用、符合署名要求的图表分享及有限简短引用；2.4 限制原始数据和结构化导出再分发；2.5 对模型评测、比较或选型类产品要求事先书面同意。本站属于比较和选型用途，不能把免费 API、手工抄录、少量成绩或非商业开源视为已有授权。

本批不接入 AA API，不收录其数值、排名、截图或衍生评分；需要入口时链接原站。后续需分别确认展示、混合其他来源、历史缓存、GitHub JSON 与源码包下载的权限。授权前不将 AA 响应写入仓库或公开产物。自行复现公开基准需遵循基准许可，结果标为本站实测，不能称为 AA 成绩。

### 开放结果与独立性

Epoch AI 自测数据按 [CC BY 4.0 说明](https://epoch.ai/benchmarks/use-this-data)保留出处、模型标识、原始单位及运行日期；其外部汇总不能套用自测数据许可。MTEB [结果仓库](https://github.com/embeddings-benchmark/results)明确为 CC0，但收录和提交不等同独立复测，仍需核实原评测者。EvalPlus [官方网站仓库](https://github.com/evalplus/evalplus.github.io)的结果文件按 Apache-2.0 核对，并保留所需声明；没有精确型号成绩时不得借用更大尺寸或新版模型。

开放许可不证明分数可靠。保留原始成绩和来源条件，原模型官方报告与外部独立评测的差异必须说明，不对分数求平均。社区提交若未确认评测者，不用于“官方与第三方交叉核实”状态。只读审计使用的下载缓存不进入公开仓库或源码包。

## 维护与验收

核对具体型号、评测者、数值单位、方向、条件、出处和使用范围，保留可审查差异并刷新核实日期。运行 `npm test`、`npm run build`，再以项目 Playwright MCP 验证全目录详情、证据展开、来源、多模型对比、证据不足模型、窄屏与无 JavaScript 阅读。负例覆盖重复评测 ID、错误用途、无效引用、状态不一致、百分比范围和同组条件冲突；目录测试还检查每个用途具有审核结论，并拒绝 AA 成绩。测试结束关闭本次浏览器与预览进程，按 AST 更新 Graphify 并保留解析限制；部署另行核实。

自动来源同步与本站推理实测为后续工作。具体出处见 [来源记录](SOURCES.md)，JSON 维护规则见 [内容指南](CONTENT_GUIDE.md)。
