# 能力依据与评测整理

## 范围

能力依据由按用途的编辑结论、原始评测成绩、评测条件及来源组成。结论帮助判断适用场景，不是通用智能等级，也不是本站推理实测。首批对象为 Gemma 4 E2B IT、Qwen3.5-4B、Qwen3-4B、Qwen3-Embedding-0.6B、Whisper small 和 PP-OCRv5 mobile rec；其他模型保留证据空态。仍使用人工核实、JSON 维护与 Astro 静态发布，不新增数据库、在线抓取或推理服务。

## 编辑规则

首批包含 20 条成绩和 12 条用途摘要，均标为官方报告依据；尚未加入独立第三方复测或本站实测。公开条件不足的记录全部保留不可比状态。

- 每个用途单独判断。英文知识成绩不外推中文写作，图像理解成绩不外推语音能力，OCR 文字行识别不外推完整文档流程。
- 只摘录准确对应型号的少量指标事实，链接具体报告；不能把其他尺寸、英文专用变体、蒸馏模型或完整流水线的成绩移植到当前型号。
- 按实际评测者标记官方、第三方或本站实测。官方数据被转载不构成独立复测，排行榜收录也不自动构成独立证据。
- `assessments` 为本站原创编辑总结，关联同用途评测 ID。优势和限制由证据支持，不依据一个高分断言“最佳”“中文优秀”或实际部署表现。
- 证据状态与能力高低分开：`official-only` 为仅官方报告，`corroborated` 为多来源佐证，`insufficient` 为证据不足。独立性仍需人工审查，结构校验不能代替事实核实。
- 不求官方与第三方成绩平均数，不制作跨用途总分。保留条件差异；低分、失败和未知不能选择性删除。
- 条件未知保留 `null` 或 `unknown`，不能从使用示例反推评测设置。核实日期不是评测日期或权重 revision。

## 数据与展示

结构以 [catalog.ts](../src/lib/catalog.ts) 为准。原有评测字段保留，新增记录身份 `id`、任务 `task`、评测者 `publisher` 和 `externalModelId`；`modelConfig` 记录权重 revision、思考模式、量化和运行时；`conditions` 记录划分、shot 数、提示模板和输出预算；`comparisonGroup` 与 `nonComparableReason` 明确比较资格；`rights` 记录使用口径、许可链接和说明。

模型顶层 `assessments` 按用途记录结论、优势、限制和关联 `evidenceIds`，缺省为空数组。详情与对比复用 `CapabilityEvidence.astro`，显示用途标签、证据状态、编辑结论、成绩及来源，原生 `details/summary` 展开条件和日期。每个用途均保留覆盖反馈，没有记录时说明证据不足，不显示虚构的 0 分。详情阅读和证据展开不依赖 JavaScript；对比沿用已有 URL 选择。

## 可比性与单位

不可比记录必须 `comparisonGroup: null` 并填写原因。可比记录需有组 ID 与明确关键配置；同组任务、基准、数据集、语言、指标、单位、方向、版本、思考模式、量化、运行时与条件不得冲突。模型 revision 区分工件，不要求不同模型 revision 字符串相同。

百分比按 `unit: "%"` 保存，普通准确率百分数为 0–100；WER/CER 因插入错误可超过 100%，不套用准确率上限。比例不能未经说明改成百分数，不同单位不能混排；0 是有效成绩，不是缺失值。平均值保留聚合口径，量化成绩只代表对应工件，API 速度不代表本地设备速度。公开报告条件不足仍可注明限制后引用，但不能加入可比组；记录完整也不保证基准无污染或适用于全部真实任务。

## 来源与使用条件

`rights.status` 区分 `citation`（少量事实引用）、`open-data`（核实开放结果数据许可）和 `site-owned`（本站产生的数据）。模型权重、工具代码、结果数据和报告文字许可分别处理。`citation` 不是整份报告或数据集再分发授权，`license: null` 不是“免费开放”。用本站文字表达，保留出处，不复制大段文字、整张官方表格或截图。

### Artificial Analysis

2026-10-02 核对 [AA 数据平台条款 v1.1](https://artificialanalysiscdn.com/legal/ProDataPlatformTerms.pdf)（2026-08-19 修订）及 [API 文档](https://artificialanalysis.ai/data-api/docs)。2.3 允许内部使用、符合署名要求的图表分享及有限简短引用；2.4 限制原始数据和结构化导出再分发；2.5 对模型评测、比较或选型类产品要求事先书面同意。本站属于比较和选型用途，不能把免费 API、手工抄录、少量成绩或非商业开源视为已有授权。

本批不接入 AA API，不收录其数值、排名、截图或衍生评分；需要入口时链接原站。后续需分别确认展示、混合其他来源、历史缓存、GitHub JSON 与源码包下载的权限。授权前不将 AA 响应写入仓库或公开产物。自行复现公开基准需遵循基准许可，结果标为本站实测，不能称为 AA 成绩。

## 维护与验收

核对具体型号、评测者、数值单位、方向、条件、出处和使用范围，保留可审查差异并刷新核实日期。运行 `npm test`、`npm run build`，再以项目 Playwright MCP 验证六个详情、证据展开、来源、多模型对比、无证据模型、窄屏与无 JavaScript 阅读。负例覆盖重复评测 ID、错误用途、无效引用、状态不一致、百分比范围和同组条件冲突。测试结束关闭本次浏览器与预览进程，按 AST 更新 Graphify 并保留解析限制；部署另行核实。

自动来源同步与本站推理实测为后续工作。具体出处见 [来源记录](SOURCES.md)，JSON 维护规则见 [内容指南](CONTENT_GUIDE.md)。
